# UX

- The session header, model and tools are not locked and when the chat continue they will be pushed off the screen. Prefer it locked

- Currently there's no way to see old chats like scrolling in the old tool maybe we should updated that

- Input box, if the string goes too long, it go off the screen and the user cannot see what they are entering. Additionally, shift enter (new line like in ms teams or any chat) does not work. Would prefer this to work. Finally input box have no indication it is selected. (normally tax box would have a flashing block or line to hint it is selected.)

- thinking tab when model is processing. RIght now thinking is the only tag which is not useful. Would prefer to see thinking, writing_tool_call (like what exactly the model is doing)

- prompt token. This does not update until a chat is complete. Not useful when chat is running. would prefer this to be cumulative

- the stop generating key (CTRL+C) conflict with the termination command in almost all platform, we would like to prevent that as we just want to stop the chat but not terminate the app.
